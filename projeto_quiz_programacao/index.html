🎯 O que é o CodeQuiz?

CodeQuiz é uma plataforma interativa de perguntas e respostas sobre programação. Desafie seus conhecimentos em JavaScript, Python, CSS, SQL, Algoritmos e muito mais. Cada sessão é cronometrada para tornar o desafio ainda maior!

⚙️ Como Funciona

  • Escolha uma categoria de programação
  • Selecione a dificuldade (Fácil, Médio ou Difícil)
  • Responda as 10 questões dentro do tempo
  • Use dicas quando necessário (custa 5 pontos)
  • Veja sua pontuação e revise as respostas

💡 Sistema de Pontuação

  • Resposta correta: +10 pontos
  • Bônus por velocidade: até +5 pontos extras
  • Usar dica: -5 pontos
  • Resposta errada: 0 pontos
  • Tempo esgotado: 0 pontos

🏆 Categorias Disponíveis

  • ⚡ JavaScript — Closures, async, DOM, prototypes
  • 🐍 Python — Sintaxe, listas, dicionários, funções
  • 🎨 CSS — Flexbox, Grid, animações, seletores
  • 🔢 Algoritmos — Ordenação, busca, complexidade
  • 🗃️ SQL — Queries, JOINs, índices
  • 🌐 Geral — Conceitos de TI e redes
